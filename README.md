# 미로찾기 (Maze Runner)

브라우저에서 바로 즐기는 미로 탈출 게임. 의존성 없는 단일 HTML 파일입니다.

## 플레이

`index.html`을 브라우저에서 열면 끝입니다. GitHub Pages로 배포하면 웹에서 바로 플레이할 수 있습니다.

## 기능

- DFS 백트래킹으로 매번 새로 생성되는 미로 (정답 경로가 항상 존재)
- 난이도 4단계: 쉬움 10×10 / 보통 16×16 / 어려움 24×24 / 악몽 34×34
- 방향 전환과 걷기 모션이 있는 사람 캐릭터
- 지나온 길 표시 (되돌아가면 자동으로 지워짐)
- 타이머, 이동 횟수, 난이도별 최고기록 저장
- 방향키 / WASD, 모바일 스와이프 및 D-패드 지원
- 다크 모드 자동 대응

## 조작

| 입력 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| 스와이프 | 이동 (모바일) |
| 새 미로 | 같은 난이도로 새 미로 생성 |
| 처음부터 | 현재 미로를 시작 지점부터 다시 |
